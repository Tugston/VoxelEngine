Detailed Description

GLFW window wrapper class.

This class simplifies some of the GLFW window functions and utilities. Plus it abstracts a lot of the base setup from the application.

Note
This class includes functions that modify the native window's properties that are not included in glfw. Please see the Native Functions group.
