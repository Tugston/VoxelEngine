bool Viper::Logger::Init ( )
static

Formats and setus up spd_log and verifies setup.

Sets the pattern of the spd_log s_EngineLogger, assigns a multithreaded logger object to the s_EngineLogger, sets the level to trace. Proceeds to do the same for the s_GameLogger and s_EditorLogger. All loggers have the same patters setup of being highlighted by their severity color, displaying time in brackets, outputting logger name, and finally the formatted message.

Postcondition
Loggers are fully setup and initialized to print outputs.
Returns
True if all loggers are successfully created and initialized. Return false otherwise.

template<typename... Args>
void Viper::Logger::LogMessage ( LogType type,
std::string_view message,
Args &&... args )
inlinestatic

Prints the provided message to the screen with args based on LogType.

Utilizes std::vformat to emplace the arg values into the printed message. Checks to see what LogType value was provided and utilizes a series of macros to print the appropriate severity through the correct logger.

Parameters
[in]typeThe severity of the log to be printed.
[in]messageString to be printed to the console.
[in]argsVariable values to display in the string.
Note
In order to display the args, add a {} for each value where it should be displayed. Then add the args in the order of the required printing.
