Calculates an orthogonal third direction from two uninstantiated vectors.

Subtracts the first Vector2 x from the second Vector2 y. Perform the same operation for the first Vector y and second Vector2 x. Then subtract both results.

Returns
The calculated orthogonal vector.
Note
Order of the parameters matter. Swapping the first and second Vector2 causes a positive and negative cross product differential.

Calculates an orthogonal third direction from both vectors utilizing the current one.

Subtracts the current Vector2 x from the other's y. Performs the same operation for the other two parameters. Finally subtracts both results. This operation follows the (flat) Left Hand rule.

Returns
The calculated orthogonal vector.

Vector2 Viper::Maths::Vector2< t >::Normalize ( )
inline

Resize the Vector2 down to a scaled direction between 0 and 1 while maintaining relevancy.

Calculates the total length of the Vector2 by square rooting the results of x squared added to y squared. Then the final normalized vector has x and y divided by this length value.

Returns
The normalized value between 0 and 1 that is relevant to the original value.
Warning
As of version 0.0.2, this function will have a serious problem if you hit the max size of t, ie (t_max * t_max). This issue is technically present for all the functions in the Vector2. As of the current version, the solution is to not intentionally cause undefined behavior by Signed Overflow.
