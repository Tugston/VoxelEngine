Detailed Description

Viper's math translation utility functions.

These functions are responsible for converting all available engine math types to glm values. This translation layer is needed for different rendering libraries. Some libs use their coordinate systems differently, and having this translation layer allows the game math to all remain the same. When a different renderer is being used, these functions will adapt properly. As of version 0.0.2 the engine only utilizes OpenGL, but Vulcan may be supported eventually.

Note
This header is not exposed to the engine API whatsoever.

glm::mat4 Viper::Maths::Transform3DToModelMatrix ( const Vector3< t > & location,
const Vector3< t > & rotation,
const Vector3< t > & scale )

Create a model matrix from a Viper transform.

Assigns a default glm mat4 model matrix. Translate the model matrix by converting the provided location to glm. Set the rotation by assigning glm rotate on each of the rotation parameter's values. Lastly set the scale value to the model matrix by converting the Vector3 scale to glm vec3, and finalize the full model matrix.

Parameters
[in]locationThe position of the model matrix to be calculated.
[in]rotationThe rotation of the model matrix to be calculated.
[in]scaleThe scale of the model matrix to be calculated.
Returns
The final matrix which is placed in the world space.
