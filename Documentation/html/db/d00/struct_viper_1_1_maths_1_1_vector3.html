const Vector3< t > & second )
inlinestatic

Calculates an orthogonal third direction based on the two provided Vector3 parameters.

Subtracts the prodcut of this Vector3's z and the other Vector3's y from the product of this Vector3's y and the other Vector3's z. Utilizes this value as the new x value. Then subtracts the product of this x and other's z from the product of this z and other's x for the new y value. Finally subtract the prodcut of this y and other's x from the product of this x and other y. Utilize this as the new Z value. Utilizes the left hand rule for the calculation. Static function to allow the calculation to be done with uninstantiated Vector3's.

Visualization of Operation

return Vector3<t>{
(y * other.z) - (z * other.y),
(z * other.x) - (x * other.z),
(x * other.y) - (y * other.x)
}

Vector3 Viper::Maths::Vector3< t >::Normalize ( )
inline

Resize the Vector2 down to a scaled direction between 0 and 1 while maintaining relevancy.

Calls Length() to get the total length of this Vector3 from the world origin. Then the final normalized vector has x, y, and z divided by the calculated length value.

Returns
The normalized value between 0 and 1 that is relevant to the original value.
Warning
As of version 0.0.2, this function will have a serious problem if you hit the max size of t, ie (t_max * t_max). This issue is technically present for all the functions in the Vector2. As of the current version, the solution is to not intentionally cause undefined behavior by Signed Overflow.
