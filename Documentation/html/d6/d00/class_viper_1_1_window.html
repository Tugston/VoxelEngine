Setup a window with a custom name and dimensions.

The constructor sets m_Info name value, width value, and height value to the provided values. Then it proceeds to call the InitializeGLFW() and SetupWindow() functions.

Parameters
[in]nameProvide a string value for the window name.
[in]widthAssign a width to the window, which is adjustable.
[in]heightAssign a height value to the window, which is adjustable.
Note
Width and height params at most will ever need to be 7680 x 4320 for 8k monitor resolutions. An unsigned short provides plenty of overhead above that. Could use an integer, but it never hurts to save a miniscule amount of memory.

◆ SetFrameSize()

void Viper::Window::SetFrameSize ( WindowResizeCallback callbackFunction)

Registers a callback function to handle framebuffer resize events.

Stores the provided callback function in the m_Info variable and registers a GLFW framebuffer size callback. When the framebuffer is resized, GLFW invokes the registered callback, which retrieves the WindowInfo associated with the window and invokes the stored resize callback with the new framebuffer width and height. The callback is invoked only if the window's user pointer resolves to a valid WindowInfo pointer.

Parameters
callbackFunctionThe function to invoke when the framebuffer is resized. Receives the new framebuffer width and height.
Note
The callback reports framebuffer dimensions in pixels, which may differ from the window dimensions on high-DPI displays.
Postcondition
The provided callback is stored in the window's internal state, replacing any previously stored resize callback, and the GLFW framebuffer resize callback is registered for this window.

◆ SetupWindow()

void Viper::Window::SetupWindow ( )
private

Initializes and creates the GLFW rendering window.

Configures the requested OpenGL context settings. Then, the function creates the window using the dimensions and name stored in the m_Info that is initialized in the constructor. The initial frame buffer dimensions are retrieved, and the OpenGL context is set. It associates the m_Info with the window user pointer, and finally sets vsync enabled. Logs the process throughout window creation.

Note
As of version 0.0.2 vsync is hard coded into the window. There is an assigned github issue to allow vsync settings to be enabled and disabled.
Precondition
GLFW must have been successfully initialized before this function is called.
The m_Info struct must be setup in the Window constructor.
Postcondition
m_RenderWindow references the created window if successfully created.
m_Info is set with the appropriate resizeCallback.
Note
requests an OpenGL 4.1 core profile with forward compatibility enabled.

◆ SetWindowBorderColor()

void Viper::Window::SetWindowBorderColor ( const Maths::Vector3< uint8_t > & color) const

Sets the thin outside frame color on a bordered window.

The function is called and receives the color as a param. The GLFW window is checked and the base Win32 window is fetched. The color is logged, confirming the setting. Then the dwmapi is utilized to set the border accordingly.

Parameters
[in]colorThe R, G, B value with a max of 255. The type is custom from Maths::Vector3
Postcondition
The window is adjusted to the provided color.
If either window is invalid, returns with no changes.
