◆ Construct()

virtual void Viper::ScriptModule::Construct ( )
pure virtual

Official constructor for the ScriptModule supported by the engine.

This construct function will be called and processed while the editor application is running and is guranteed to occur before Start(). This is called as soon as the Script is instantiated on the Scene::ECS::Components::ScriptComponent. In version 0.0.2 this feature is not implemented as of yet because the editor is still a work in progress.

Postcondition
The script is prepared for Start().

◆ SetOwner()

void Viper::ScriptModule::SetOwner ( Scene::ECS::GameObject * ownerRef)
inlinenoexcept

Assign the owner of the script for simple reference.

The scripts may need to interact with other entities attached to this entity. This checks if the owner is not already set as well if the ownerRef parameter is valid. If not, simply return without doing anything.

Parameters
[in]ownerRefReference to the entity that this script is attached to.
Note
In future versions this GameObject param will need to be exchanged to just and entityID. As of version 0.0.2 having a GameObject passed in for the owner prevents the script module from working with the core ECS.
