Detailed Description

The overarching class for engine processes.

This is the main driver signleton class that controls all the backend engine tasks such as rendering, calculating delta, engine setup, providing api, etc.

Warning
Be sure to define CreateApplication in your game, see the CreateApplication function for specific details.
Note
For a list of all functions available for use in your game, check the Engine API.
