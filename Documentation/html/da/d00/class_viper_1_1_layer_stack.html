void Viper::LayerStack::Clear ( )
static

Clear all layers entirely.

Checks if m_Layers actually has layers, if not return. If it does, loop through each layer deleting the pointer. Then finally clear the vector itself.

Postcondition
m_Layers is full cleared completely.

◆ PushUILayer()

void Viper::LayerStack::PushUILayer ( Layer * layer)
static

Add a Layer object to the stack of a UI type.

Pushes back a new Layer at the very end of m_Layers. Then the pure virtual Layer::Attach() function is called to setup the layer itself. The m_EmplaceIndex does not require being updated because this adds layers to the very back anyways. Log a message to state if everything attached and setup properly.

Note
These are the UI layers for both the engine debug, game, and game debug.
Parameters
[in,out]layerThe specific layer type to be added, must be a child of UILayer, UIDebugLayer, or EngineUILayer.
Returns
True if the layer was successfully setup and added, false otherwise.

◆ PushWorldLayer()

void Viper::LayerStack::PushWorldLayer ( Layer * layer)
static

Add a Layer object to the stack of a world type.

Inserts a new Layer right before the CurrentLocation() iterator. Then the function calls the pure virtual Layer::Attach() function to setup the layer itself. If the setup is successful, incriment m_EmplaceIndex by one and log success. Otherwise, log a failure message.

Note
These are the actual scene layers for both engine debug and game world.
Parameters
[in,out]layerThe specific layer type to be added, must be a type of WorldLayer or EngineWorldLayer.
Returns
True if the layer was successfully setup and added, false otherwise.
