◆ CalculateDeltaTime()

void Engine::Application::CalculateDeltaTime ( )
private

Calculates the delta time between each frame.

This function calculates delta time by subtracting the glfw runtime by m_PreviousTime, then assigns it as the new m_PreviousTime. This functions handles the calculation for the m_FrameRate as well.

Postcondition
The m_DeltaTime and m_FrameRate values are set each frame

◆ Draw()

void Engine::Application::Draw ( float deltaTime)
private

Handles all draw calls in the application.

Begins the frame rendering using the m_Renderer by calling Renderer::Renderer::BeginRender() and supplying the current camera. Performs all rendering calls in proper order and then calls Renderer::Renderer::EndRender() to finalize the drawing, cleanup, and render the scene. Finally calls SwapBuffer() to display the frame.

Parameters
[in]deltaTimeThe current value for m_DeltaTime calculated in CalculateDeltaTime().

◆ GetCamera()

Camera::EditorCamera * Engine::Application::GetCamera ( )
inlinestatic

Free flying editor camera.

This is an editor camera and strictly meant for an editor or game debugging view. A game should utilize a Scene::ECS::Components::PerspectiveCamera or a Scene::ECS::Components::OrthographicCamera for playing.

Warning
The pointer is not checked for validity. This can return null. However, a camera should always be valid.
Note
As of version 0.0.2 the camera components do not exist yet. So, the Camera::EditorCamera may turn into more of a camera management system. The editor camera itself will just be a ECS component... maybe?
Returns
The current pointer stored in m_Camera variable.

◆ Tick()

void Engine::Application::Tick ( )
virtual

Begin the main event loop of the entire application.

Tick immediately calls CalculateDeltaTime() for the next update, then input events are processed, Tick is called for all scripts, the m_Window polls for events, and finally Draw() is called.

Note
The Tick function does not incorprate the loop itself. This must be created in the game's Tick. Also, the engine's Tick function must be called last inside the loop. Various systems are polling for events that the Engine Tick handles. Delta Time can be acquired by calling GetDeltaTime().

◆ m_PreviousTime

float Engine::Application::m_PreviousTime = 0
private

Temporary value for the m_DeltaTime calculation.

The CalculateDeltaTime() function needs a way to remember the previous runtime before this value is set. So, it needs a variable storage value and cannot be a static variable in the function because the value is needed before.
