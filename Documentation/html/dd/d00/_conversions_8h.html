unsigned int Viper::Maths::RGBtoHex ( const Vector3< uint8_t > & color)

Convert a general rgb color to a Hexadecimal representation of the same color.

Converts the Vector3 holding rgb values to hexadecimal by bit shifting the x (red) over 2 bytes, the y (green) over 1 byte, and the z (blue) over by a single byte.

Parameters
[in]colorThe rgb color needing to be converted.
Returns
A compacted hexadecimal color inside an integer.
