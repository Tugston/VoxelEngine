Detailed Description

Utility functions for generating various random values.

Available functions for Generating random floats, random integers, and random characters in range. These functions also provide a scaled variant that allow a value from 0 - 1 for example. Also have functions for random characters, booleans, and these have scaled alternative functions as well.

◆ InitializeRandomGenerators()

bool Viper::Utility::InitializeRandomGenerators ( )

Initializes the random number generators used by the application.

Seeds the standard library random number generator using the current system time and initializes the Mersenne Twister engine using a seed obtained from std::random_device.

Returns
True upon completion
Warning
This is for internal engine use setup only! Please do not override or call in any derived applications. The function is exposed to do so, but it will reset the generators and cause unpredictable behaviour.
