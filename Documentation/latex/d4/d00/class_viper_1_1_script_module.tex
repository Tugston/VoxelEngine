Official constructor for the \doxylink{class_viper_1_1_script_module}{Script\+Module} supported by the engine. 

This construct function will be called and processed while the editor application is running and is guranteed to occur before \doxylink{class_viper_1_1_script_module_a368cf100e5e836e49105e80a2c0250cf}{Start()}. This is called as soon as the Script is instantiated on the \doxylink{struct_viper_1_1_scene_1_1_e_c_s_1_1_components_1_1_script_component}{Scene::\+\+ECS::\+\+Components::\+\+Script\+Component}. In version 0.\+0.\+2 this feature is not implemented as of yet because the editor is still a work in progress.

\begin{DoxyPostcond}{Postcondition}

Assign the owner of the script for simple reference. 

The scripts may need to interact with other entities attached to this entity. This checks if the owner is not already set as well if the owner\+Ref parameter is valid. If not, simply return without doing anything.
