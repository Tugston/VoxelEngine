\doxysubsection{Detailed Description}
Contains global types, macros, and values for the engine, game, and editor. 

Detects the os through premake build, currently only supported on Windows. Adds the assertion macro for major fatal errors that are better for the application to crash than continue. Defines GLFW\+\_\+\+INCLUDE\+\_\+\+NONE to allow application to handle gl.\+h. Defines various types and provides base utility macros.
