Registers a callback function to handle framebuffer resize events. 

Stores the provided callback function in the \doxylink{class_engine_1_1_window_a76d644443b09e0ffa1b29d82b433dec0}{m\+\_\+\+Info} variable and registers a GLFW framebuffer size callback. When the framebuffer is resized, GLFW invokes the registered callback, which retrieves the \doxylink{struct_engine_1_1_window_1_1_window_info}{Window\+Info} associated with the window and invokes the stored resize callback with the new framebuffer width and height. The callback is invoked only if the window\textquotesingle{}s user pointer resolves to a valid \doxylink{struct_engine_1_1_window_1_1_window_info}{Window\+Info} pointer.

\end{DoxyNote}

Initializes and creates the GLFW rendering window. 

Configures the requested Open\+GL context settings. Then, the function creates the window using the dimensions and name stored in the \doxylink{class_engine_1_1_window_a76d644443b09e0ffa1b29d82b433dec0}{m\+\_\+\+Info} that is initialized in the constructor. The initial frame buffer dimensions are retrieved, and the Open\+GL context is set. It associates the \doxylink{class_engine_1_1_window_a76d644443b09e0ffa1b29d82b433dec0}{m\+\_\+\+Info} with the window user pointer, and finally sets vsync enabled. Logs the process throughout window creation.

\begin{DoxyNote}{Note}
As of version 0.\+0.\+2 vsync is hard coded into the window. There is an assigned github issue to allow vsync settings to be enabled and disabled.
\end{DoxyNote}
\begin{DoxyPrecond}{Precondition}
GLFW must have been successfully initialized before this function is called. 

The \doxylink{class_engine_1_1_window_a76d644443b09e0ffa1b29d82b433dec0}{m\+\_\+\+Info} struct must be setup in the \doxylink{class_engine_1_1_window}{Window} constructor.
\end{DoxyPrecond}
\begin{DoxyPostcond}{Postcondition}
m\+\_\+\+Render\+Window references the created window if successfully created. 

m\+\_\+\+Info is set with the appropriate resize\+Callback.
\end{DoxyPostcond}
\begin{DoxyNote}{Note}
requests an Open\+GL 4.\+1 core profile with forward compatibility enabled. 
\end{DoxyNote}

Sets the top bar color on a bordered window. 

The window heading color is received as a param. The GLFW window is checked and the base Win32 window is then fetched. The color is logged for verifications. Finally the dwmapi is utilized to set the header color accordingly.
