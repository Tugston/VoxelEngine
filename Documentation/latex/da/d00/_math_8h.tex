\doxysubsection{Detailed Description}
Viper\textquotesingle{}s own math library implementation which supports only the supported types used by the engine. 

This math library is utilized in order to abstract glm from the user application. As of version 0.\+0.\+2 it provides Vectors and Rotators in both 2d and 3d with full math utility functions for each. Some utilities are statically copied as well to provide calculations without instantiating a new class object.
