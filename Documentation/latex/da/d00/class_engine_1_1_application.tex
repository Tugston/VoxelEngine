Handles all draw calls in the application. 

Begins the frame rendering using the m\+\_\+\+Renderer by calling Renderer::\+\+Renderer::\+\+Begin\+Render() and supplying the current camera. Begin the main event loop of the entire application. 

Tick immediately calls \doxylink{class_engine_1_1_application_a7c03874deb6fd6484ed179ba4f37a600}{Calculate\+Delta\+Time()} for the next update, then input events are processed, Tick is called for all scripts, the m\+\_\+\+Window polls for events, and finally \doxylink{class_engine_1_1_application_acbe20aa5886a591958c12937ea8bde04}{Draw()} is called.

\begin{DoxyNote}{Note}
The Tick function does not incorprate the loop itself. This must be created in the game\textquotesingle{}s Tick. Also, the engine\textquotesingle{}s Tick function must be called last inside the loop. Various systems are polling for events that the Engine Tick handles. Delta Time can be acquired by calling \doxylink{class_engine_1_1_application_ab74e908f50c64b5fa86d35dc0d2928cf}{Get\+Delta\+Time()}. 
\end{DoxyNote}
