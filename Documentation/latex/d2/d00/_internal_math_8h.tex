\doxysubsection{Detailed Description}
Viper\textquotesingle{}s math translation utility functions. 

These functions are responsible for converting all available engine math types to glm values. This translation layer is needed for different rendering libraries. Some libs use their coordinate systems differently, and having this translation layer allows the game math to all remain the same. When a different renderer is being used, these functions will adapt properly. As of version 0.\+0.\+2 the engine only utilizes Open\+GL, but Vulcan may be supported eventually. \begin{DoxyNote}{Note}
This header is not exposed to the engine API whatsoever.
\end{DoxyNote}

Create a model matrix from a Viper transform. 

Assigns a default glm mat4 model matrix. Translate the model matrix by converting the provided location to glm. Set the rotation by assigning glm rotate on each of the rotation parameter\textquotesingle{}s values. Lastly set the scale value to the model matrix by converting the Vector3 scale to glm vec3, and finalize the full model matrix.
