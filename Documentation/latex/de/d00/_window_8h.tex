\doxysubsection{Detailed Description}
GLFW window wrapper class. 

This class simplifies some of the GLFW window functions and utilities. Plus it abstracts a lot of the base setup from the application.

\begin{DoxyNote}{Note}
This class includes functions that modify the native window\textquotesingle{}s properties that are not included in glfw. Please see the \doxylink{class_engine_1_1_window_native_functions}{Native Functions} group.
\end{DoxyNote}
