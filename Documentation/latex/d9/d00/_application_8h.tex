\doxysubsection{Detailed Description}
The overarching class for engine processes. 

This is the main driver signleton class that controls all the backend engine tasks such as rendering, calculating delta, engine setup, providing api, etc.

\begin{DoxyWarning}{Warning}
Be sure to define Create\+Application in your game, see the \doxylink{_application_8h_create_application}{Create\+Application} function for specific details. 
\end{DoxyWarning}
