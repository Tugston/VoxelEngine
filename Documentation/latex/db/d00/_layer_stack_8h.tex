\doxysubsection{Detailed Description}
Controls and groups the rendering and input order. 

The layer system is a very simple setup. Each scene consists of the same four layers in non dist builds. The dist build does not need engine features, so these are removed and only the game layers are present. The layer orders are as follows...

\doxylink{class_viper_1_1_world_layer}{Viper::\+\+World\+Layer} (Game World) -\/\texorpdfstring{$>$}{>} \doxylink{class_viper_1_1_engine_world_layer}{Viper::\+\+Engine\+World\+Layer} (line traces, collision boxes, etc) -\/\texorpdfstring{$>$}{>} \doxylink{class_viper_1_1_u_i_layer}{Viper::\+\+UILayer} -\/\texorpdfstring{$>$}{>} \doxylink{class_viper_1_1_engine_u_i_layer}{Viper::\+\+Engine\+UILayer} (Engine details)

This system is primarily meant to render the Game\textquotesingle{}s UI on top of the Game\textquotesingle{}s scene rendering. Every scene follows this same order and process, so the Layer\+Stack class is static.
